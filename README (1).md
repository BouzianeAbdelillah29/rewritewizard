# RewriteWizard

AI-based text rewriting application — **Bachelor's thesis (2020–2023)**, University of Saad Dahlab, Blida, Algeria.

## Overview

RewriteWizard helps users rephrase and improve written content. It applies natural language processing (NLP) techniques to generate alternative versions of text while preserving its original meaning. It works **contextually** — considering the surrounding text — rather than replacing words in isolation.

### Features

- **Grammar checking** — detects and corrects grammatical errors in written text
- **Paraphrasing** — rewrites sentences and paragraphs with preserved meaning
- **Context-aware rewriting** — analyzes surrounding context so rewrites stay natural and fluent, not just word-by-word substitution
- **Summarization** — condenses longer texts into concise summaries

## Tech stack

- Python
- NLTK, Gensim
- scikit-learn

## Usage

1. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Launch the application:
   ```bash
   python main.py
   ```
   *(replace `main.py` with the project's entry-point file)*
